# 🚀 Anand Reddy Palle - Java Full Stack Developer Portfolio (Frontend)

A modern, responsive, and high-performance developer portfolio built with **React 19**, **Tailwind CSS**, and **Vite**. Connected to a live **Spring Boot 3** & **PostgreSQL** cloud backend deployed on Render.

---

## 🌟 Key Highlights

- **Live Backend Integration**: Seamlessly communicates with the cloud backend API (`POST /api/contacts`, `GET /api/projects`, `GET /api/skills`).
- **Modern Clean Design**: Professional light-mode UI inspired by modern engineering standards, featuring subtle borders, high-contrast typography, and intuitive UX.
- **Dynamic Contact Workflow**: Visitors can submit messages that are directly stored in a live PostgreSQL database on Render.
- **Fully Responsive**: Mobile-first design optimized for all screen sizes from mobile to wide desktops.
- **Fast Build Times**: Powered by Vite and Tailwind CSS v4 for sub-second builds and HMR.

---

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: React Icons (Feather)
- **HTTP Client**: Axios
- **Backend API**: [Spring Boot 3 + PostgreSQL](https://github.com/Anandpalle/portfolio) (Deployed on Render)

---

## ⚙️ Environment Configuration

Create a `.env` file in the root directory:

```env
# Render Cloud Backend API URL
VITE_API_BASE_URL=https://portfolio-backend-nanr.onrender.com/api
```

---

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Anandpalle/portfolio-frontend.git
   cd portfolio-frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Production Build:**
   ```bash
   npm run build
   ```
